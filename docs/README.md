## 常用速查

**导出文件编号**（按本次实际生成的类型动态排列）：

| 场景 | 文件 |
|---|---|
| 只导出采购 | `01_采购报销明细`、`02_采购报销清单`、`03_采购报销验收单` |
| 只导出出行 | `01_出行报销明细`、`02_出行报销验收单` |
| 采购 + 出行 | `01`–`03` 为采购，`04` 出行明细、`05` 出行验收单 |

**离线识别引擎**：

| 平台 | 引擎 |
|---|---|
| Windows | Windows.Media.Ocr（系统自带） |
| Ubuntu / Debian | Tesseract（`chi_sim+eng`） |
| macOS | Tesseract（`brew install tesseract tesseract-lang`） |

PDF 文字层不依赖 OCR，电子发票优先走文字层解析。
