# 票管家 · 接口文档

后端 HTTP API 参考，对应 `server/internal/api` 中的路由与 handler。当前版本 **v1.1.0**。

- Base URL：`http://<host>:8686`
- 认证：除标注「公开」外，均需请求头 `Authorization: Bearer <token>`
- 下载类接口（导出、备份、附件）额外支持 `?token=<token>`，方便浏览器直接打开
- 统一返回 JSON；错误格式：`{ "error": "提示文案", "code": "错误码" }`
- 金额单位为元，时间统一使用 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm:ss`

## 上传与识别

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/uploads` | `multipart/form-data`，字段名 `file`；落盘临时目录、执行识别，返回 `token` 与解析结果 |

限制：单文件 20MB（可配置）、扩展名 `pdf,jpg,jpeg,png,webp,bmp`；单次提交最多 8 个附件。

```json
{
  "token": "AbC123...",
  "file": { "name": "invoice.pdf", "mime": "application/pdf", "size": 147124, "ext": ".pdf" },
  "parse": {
    "kind": "vat_normal",
    "kind_label": "增值税普通发票",
    "suggest_type": "procurement",
    "engine": "pdf-text",
    "pages": 1,
    "confidence": 0.88,
    "fields": {
      "invoice_no": { "value": "26442000000123456789", "confidence": 0.98, "source": "label" },
      "invoice_date": { "value": "2026-10-21", "confidence": 0.7, "source": "label" },
      "seller": { "value": "上海云帆办公用品有限公司", "confidence": 0.9, "source": "layout" },
      "buyer": { "value": "哈尔滨剑桥学院", "confidence": 0.9, "source": "layout" },
      "amount": { "value": 215.0, "confidence": 0.9, "source": "label" },
      "tax": { "value": 27.95, "confidence": 0.9, "source": "label" },
      "total": { "value": 242.95, "confidence": 0.95, "source": "label" }
    },
    "items": [
      { "name": "A4复印纸", "spec": "70g500张/包", "unit": "包", "qty": 10,
        "price": 21.5, "amount": 215, "rate": 13, "tax": 27.95 }
    ],
    "suggest": { "type": "procurement", "title": "A4复印纸", "category": "办公用品",
                 "spec": "70g500张/包", "qty": 10, "unit_price": 24.3,
                 "shipping": 0, "amount": 242.95 },
    "warnings": [],
    "raw_text": "…",
    "elapsed_ms": 36
  }
}
```

要点：

- `engine` 取值：`pdf-text`（PDF 文字层）、`pdf-image-ocr`（PDF 内嵌图片）、`windows-ocr`（图片 OCR，macOS/Linux 下由 Tesseract 实现）、`none`（关闭识别）
- PDF 优先读文字层；文字不足 15 个汉字时才回退到图片 OCR
- `items[].unit` 会在创建票据时写入 `invoices.unit`
- `fields` 为字段级结果，含 `confidence` 与 `source`（label / layout / pattern / row / sum 等）
- `suggest` 是给上传向导的预填值，成员可在第二步修改

## 票据

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/invoices` | 创建票据 |
| GET | `/api/invoices` | 列表（分页 + 过滤） |
| GET | `/api/invoices/{id}` | 详情（含附件） |
| PATCH | `/api/invoices/{id}` | 更新状态或字段 |
| DELETE | `/api/invoices/{id}` | 软删除 |
| GET | `/api/files/{id}` | 下载 / 预览附件 |
| GET | `/api/files/{id}/thumb` | 附件缩略图（JPEG） |

`POST /api/invoices`

```json
{
  "payload": {
    "type": "procurement",
    "title": "A4复印纸",
    "category": "办公用品",
    "spec": "70g 500张/包",
    "unit": "包",
    "qty": 10, "unit_price": 24.30, "shipping": 0, "amount": 242.95,
    "note": "2026年10月办公耗材采购",
    "meta": { "invoice_no": "26442000000123456789", "invoice_date": "2026-10-21",
              "seller": "上海云帆办公用品有限公司", "buyer": "哈尔滨剑桥学院",
              "total": 242.95, "tax": 27.95, "invoice_kind": "vat_normal" },
    "ocr_engine": "pdf-text", "ocr_confidence": 0.88
  },
  "uploads": ["AbC123..."]
}
```

- `unit` 可省略：服务端会从对应上传记录的识别明细第一行取单位
- 出行类型把 `category/spec/unit/link/qty/unit_price/shipping` 换成 `travel_time/transport/route/traveler`，`amount` 为税后金额
- `uploads` 为 `/api/uploads` 返回的 token 列表，提交成功后临时文件移入附件目录并清理记录

票据对象主要字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` / `user_id` / `display_name` | number / number / string | 票据与上报人 |
| `type` | string | `procurement` / `travel` |
| `status` | string | `pending` / `reimbursed` |
| `title` / `category` / `spec` / `unit` | string | 名称、类别、规格、单位 |
| `qty` / `unit_price` / `shipping` / `amount` | number | 数量、税后单价、运费、税后金额 |
| `travel_time` / `transport` / `route` / `traveler` | string | 出行要素 |
| `invoice_no` / `invoice_date` / `seller` / `buyer` | string | 票面信息 |
| `tax` / `total` | number | 税额、价税合计 |
| `invoice_kind` / `ocr_engine` / `ocr_confidence` | string / string / number | 识别元信息 |
| `files` | array | 附件列表 |
| `created_at` / `updated_at` / `reimbursed_at` | string | 时间 |

`PATCH /api/invoices/{id}` 可更新：`status`、`title`、`category`、`spec`、`unit`、`link`、`travel_time`、`transport`、`route`、`traveler`、`note`、`qty`、`unit_price`、`shipping`、`amount`。

`GET /api/invoices` 查询参数：

| 参数 | 说明 |
|---|---|
| `page` / `page_size` | 分页，默认 1 / 20，`page_size` 最大 200 |
| `status` | `pending` / `reimbursed` |
| `type` | `procurement` / `travel` |
| `category` | 精确匹配类别 |
| `year` / `month` | 按开票日期过滤；开票日期为空时按创建日期 |
| `date_from` / `date_to` | 自定义区间 `YYYY-MM-DD` |
| `q` | 关键词，匹配名称 / 类别 / 销方 / 备注 / 票号 / 路线 / 出行人 |
| `user_id` | 管理员指定成员 |
| `scope` | `mine` 只看自己（成员端默认只看自己） |

返回：

```json
{
  "items": [
    { "id": 1, "title": "A4复印纸", "unit": "包", "qty": 10, "amount": 242.95,
      "status": "pending", "files": [{ "id": 1, "name": "invoice.pdf", "ext": "pdf", "size": 147124 }] }
  ],
  "total": 42, "sum_amount": 12345.67, "page": 1, "page_size": 20, "pages": 3
}
```

## 设置与运维

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings` | 全部设置 + OCR 可用性（登录即可） |
| PUT | `/api/settings` | 保存设置（白名单字段，仅管理员） |
| GET | `/api/admin/audit?limit=100` | 审计日志 |
| GET | `/api/admin/storage` | 票据数、附件数、占用空间 |
| POST | `/api/admin/cleanup` | 手动执行保留期清理 |
| GET | `/api/admin/backup` | 下载备份（data.json + 附件） |

> `/api/admin/*` 与成员管理接口仅管理员可调用；`GET /api/settings` 登录用户可读，写操作仅管理员。

可写设置项：

| 字段 | 说明 |
|---|---|
| `org_name` | 团队名称 |
| `categories` | 消费类别，数组或逗号分隔 |
| `max_upload_mb` | 单文件上限（MB） |
| `allowed_exts` | 允许的扩展名 |
| `retention_mode` | `permanent` / `auto` |
| `retention_days` | 保留天数 |
| `retention_scope` | `files`（只删原件）/ `all`（连记录一起删） |
| `ocr_engine` | `auto` / `windows` / `tesseract` / `none` |

## 导出

`GET /api/export?year=2026&month=10&type=procurement&status=pending&user_id=2&token=...`

| 参数 | 说明 |
|---|---|
| `year` / `month` | 按月份或年份导出 |
| `date_from` / `date_to` | 自定义区间 |
| `status` | `pending` / `reimbursed`，省略为全部 |
| `type` | `procurement` / `travel`，省略为全部 |
| `user_id` | 只导出指定成员（管理员） |
| `token` | 浏览器直接下载时替代 Authorization 头 |

返回 `application/zip`，文件名形如 `发票汇总_2026年10月_未报销_20261109_1602.zip`。

压缩包内容：

| 编号 | 文件 | 条件 |
|---|---|---|
| 01 | 采购报销明细.xlsx | 有采购票据 |
| 02 | 采购报销清单.xlsx | 有采购票据 |
| 03 | 采购报销验收单.xlsx | 有采购票据 |
| 04 | 出行报销明细.xlsx | 有出行票据 |
| 05 | 出行报销验收单.xlsx | 有出行票据 |

编号按实际生成顺序动态排列：纯出行导出时，出行明细 / 验收单为 `01 / 02`；采购 + 出行同时存在时才排到 `04 / 05`。没有数据的类型不生成文件，也不占号。

Excel 说明：

- `01` / `04` 各含「明细 / 汇总 / 统计」三个工作表，带冻结表头、自动筛选、合计行
- `02` / `03` / `05` 为模板填充：表头、边框、签字栏保持模板样式，明细区居中、金额两位小数
- 验收单 / 清单按 A4、73% 缩放输出；所有工作表隐藏网格线
- 附件在 ZIP 根目录按 `附件001_类别_金额元.ext` 重命名，与 Excel「附件文件」列一一对应

## 错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | `bad_json` / `bad_type` / `bad_title` / `bad_amount` | 请求参数不合法 |
| 400 | `no_upload` / `too_many` / `upload_expired` | 附件缺失、超过 8 个或临时文件失效 |
| 400 | `bad_file` / `read_error` / `storage_error` | 文件解析或落盘失败 |
| 400 | `already_setup` / `bad_username` / `bad_password` | 已初始化或账号格式不合法 |
| 400 | `empty` | 导出筛选条件下没有票据 |
| 400 | `no_change` / `bad_setting` | 更新内容为空或设置值不合法 |
| 401 | `unauthenticated` / `bad_credentials` | 未登录 / 账号密码错误 |
| 403 | `forbidden` / `inactive` | 无权限 / 账号停用 |
| 404 | `not_found` | 资源不存在 |
| 429 | `rate_limited` | 登录尝试过于频繁 |
| 500 | `db_error` / `export_error` | 服务端错误 |
