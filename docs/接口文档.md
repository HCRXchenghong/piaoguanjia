# 票管家 · 接口文档

后端 HTTP API 参考，对应 `server/internal/api` 中的路由与 handler。

- Base URL：`http://<host>:8686`
- 认证：除标注「公开」外，均需请求头 `Authorization: Bearer <token>`
- 下载类接口（导出、备份、附件）额外支持 `?token=<token>`，方便浏览器直接打开
- 统一返回 JSON；错误格式：`{ "error": "提示文案", "code": "错误码" }`

## 认证

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查（公开） |
| GET | `/api/bootstrap` | 启动信息：是否需要初始化、当前用户、公开设置（公开） |
| POST | `/api/setup` | 首次初始化管理员（公开，仅当用户表为空） |

| GET | `/api/me` | 当前用户 |
| POST | `/api/me/password` | 修改自己的密码 |

## 票据

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/invoices` | 创建票据 |
| GET | `/api/invoices` | 列表（分页 + 过滤） |
| GET | `/api/invoices/{id}` | 详情（含附件） |
| PATCH | `/api/invoices/{id}` | 更新状态或字段 |
| DELETE | `/api/invoices/{id}` | 软删除 |
| GET | `/api/files/{id}` | 下载/预览附件 |
| GET | `/api/files/{id}/thumb` | 附件缩略图（JPEG） |

`POST /api/invoices`

```json
{
  "payload": {
    "type": "procurement",
    "title": "A4复印纸",
    "category": "办公用品",
    "spec": "70g 500张/包",
    "qty": 10, "unit_price": 24.30, "shipping": 0, "amount": 242.95,
    "note": "2026年10月办公耗材采购",
    "meta": { "invoice_no": "26442000000123456789", "invoice_date": "2026-10-21",
              "seller": "上海云帆办公用品有限公司", "total": 242.95, "tax": 27.95 },
    "ocr_engine": "windows-ocr", "ocr_confidence": 0.88
  },
  "uploads": ["AbC123..."]
}
```

出行类型把 `category/spec/link/qty/unit_price/shipping` 换成 `travel_time/transport/route/traveler`，`amount` 为税后金额。

`GET /api/invoices` 查询参数：

| 参数 | 说明 |
|---|---|
| `page` / `page_size` | 分页，默认 1 / 20 |
| `status` | `pending` / `reimbursed` |
| `type` | `procurement` / `travel` |
| `category` | 精确匹配类别 |
| `year` / `month` | 按开票日期（空则按创建日期）过滤 |
| `date_from` / `date_to` | 自定义区间 `YYYY-MM-DD` |
| `q` | 关键词，匹配名称/类别/销方/备注/票号/路线/出行人 |
| `user_id` | 管理员指定成员 |
| `scope` | `mine` 只看自己（成员端默认只看自己） |

返回：

```json
{ "items": [ { "id": 1, "title": "A4复印纸", "amount": 242.95, "status": "pending",
               "files": [ { "id": 1, "name": "invoice.png", "ext": "png", "size": 147124 } ] } ],
  "total": 42, "sum_amount": 12345.67, "page": 1, "page_size": 20, "pages": 3 }
```

## 成员（管理员）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/users` | 成员列表（含票据数与累计金额） |
| POST | `/api/users` | 新建成员 |
| PATCH | `/api/users/{id}` | 改显示名/部门/角色/启停 |
| POST | `/api/users/{id}/password` | 重置密码 |
| DELETE | `/api/users/{id}` | 删除（名下有待处理票据时拒绝） |

## 设置与运维（管理员）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/settings` | 管理员返回全部设置 + OCR 可用性 |
| PUT | `/api/settings` | 保存设置（白名单字段） |
| GET | `/api/admin/audit?limit=100` | 审计日志 |
| GET | `/api/admin/storage` | 票据数、附件数、占用空间 |
| POST | `/api/admin/cleanup` | 手动执行保留期清理 |
| GET | `/api/admin/backup` | 下载备份（data.json + 附件） |

可写设置项：`org_name`、`categories`（数组或逗号分隔）、`max_upload_mb`、`allowed_exts`、
`retention_mode`（permanent/auto）、`retention_days`、`retention_scope`（files/all）、`ocr_engine`（auto/none）。

## 导出

`GET /api/export?year=2026&month=10&type=procurement&status=pending&user_id=2&token=...`

返回 `application/zip`，文件名形如 `发票汇总_2026年10月_20261109_1602.zip`。

## 错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | `bad_json` / `bad_type` / `bad_title` / `no_upload` | 参数问题 |
| 401 | `unauthenticated` / `bad_credentials` | 未登录 / 账号密码错误 |
| 403 | `forbidden` / `inactive` | 无权限 / 账号停用 |
| 404 | `not_found` | 资源不存在 |
| 429 | `rate_limited` | 登录尝试过于频繁 |
| 500 | `db_error` / `export_error` | 服务端错误 |
